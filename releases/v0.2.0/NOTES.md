# AI Team Workbench 0.2.0

Adds compact flow setup, an assignment board and public activity traces, owner questions/replies, pause/resume, quota waits, account rotation, useful backlog budgets, state/source backups and two-way Telegram/Zalo adapters.

The original VSIX is preserved byte for byte. The source ZIP is a partial recovery from the packaged source map, with the original package metadata and README/license where present. It does not include the original tests, lockfile, build scripts or Git history. Live providers and public messaging endpoints require separate configuration and validation.

Verify with `npm run releases:verify` from the current repository. See `release.json` and `SHA256SUMS` for provenance and integrity.
