# RelayCrew 0.3.0

Introduces RelayCrew branding, English documentation, MIT licensing, contribution/architecture guidance, quota source boundaries, multiple quota windows, actual running-account usage, task account pins, the system timezone default and Windows/Linux CI configuration.

The original VSIX is preserved byte for byte. The source ZIP is a partial recovery from the packaged source map, with the original package metadata and README/license where present. It does not include the original tests, lockfile, build scripts or Git history. CI configuration is not evidence of a historical remote CI run.

Verify with `npm run releases:verify` from the current repository. See `release.json` and `SHA256SUMS` for provenance and integrity.
