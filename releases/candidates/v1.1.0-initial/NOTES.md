# RelayCrew 1.1.0

Prepare a run, understand what is happening, and recover unfinished work without losing control.

- Inline run review before a composer team task: folders, permissions, account readiness, role/model policy, acceptance criteria and saved execution budgets. Confirm explicitly; changed execution settings invalidate the review.
- Shared status across Tasks, Live and Map, with observed file changes, public commands, child agents and the next required action. Updating double-click details, direction-aware layouts and readable code/table output from the 1.0.2 previews are included.
- Account cards distinguish configuration, installation, fresh connection checks, verified identity and unknown/stale quota. A profile name never proves a separate login or quota pool.
- Host interruption pauses automatic dispatch. Explicit inspected retry keeps completed steps, permissions and review/provider retry budgets.
- Portable versioned JSON session export and richer Markdown reports include public events, child reports and observed file changes without account configuration or private reasoning.
- Saved-data inspection and confirmed retention cleanup confined to workspace extension storage. Current state, referenced attachments, source snapshots, secrets and repository files are protected.
- Updated current-behavior guide, bilingual controls and automated regression coverage. One task executes per workspace runner; detached Live tabs are observers. HTTP connections remain read-only, and scheduling requires an open extension host.

No Marketplace publication, remote channel delivery or extra paid CLI demo is performed by this release workflow. Existing release archives remain immutable. Download checksums describe the particular packaged artifact; locally archived and CI-built VSIX files may differ in ZIP timestamps.
