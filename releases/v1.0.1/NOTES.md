# RelayCrew 1.0.1

A clearer start-to-live workflow, a more readable UI and real account data where supported.

- Prepare accounts, roles and Markdown before opening Live.
- Find Login, Test connection and Usage & rate limits beside each account; expand advanced settings when needed.
- Theme-aware status accents, compact responsive controls, and readable warnings in light/dark themes.
- Codex identity/plan and native quota windows; Claude identity/plan; Antigravity quota by model group for the current shared CLI login. Read-only account checks submit no model prompt.
- Independent account fallback/recovery, larger interactive maps, native Codex child observation, detachable Live/map panels and separate conversation/files/activity views.

Google profile labels do not create independent authenticated sessions. Antigravity does not expose the active email in its usage command. Claude native limits remain in `/usage` inside Claude Code. Unknown/stale quota does not authorize automatic work. Native child visibility depends on public events; workers are sequential. Real agent tasks consume provider quota.

Validation: type checking, 175 automated tests, EN/VI light/dark/narrow UI, account/recovery/preparation/live/canvas interactions, retained release checksums, and local native account reads. Text contrast for account badges/warnings passed 4.5:1 in tested light/dark palettes. Personal state, CLI copies, captures and preview pages are excluded.

## Tiếng Việt

Bản 1.0.1 có hướng dẫn chuẩn bị trước Live, danh sách tài khoản gọn với nút đăng nhập/kiểm tra/hạn mức ngay cạnh, màu trạng thái rõ và sơ đồ có thể phóng lớn. Xem riêng hội thoại, agent con, file thay đổi và nhật ký kỹ thuật; có thể tách các panel.

Codex trả danh tính/gói và quota thật; Claude trả danh tính/gói; Antigravity trả quota theo nhóm model cho phiên CLI dùng chung, chưa xác minh email Google. Không tự coi hai nhãn email là hai tài khoản đã đăng nhập độc lập. Kiểm tra tài khoản không gửi prompt model; chạy demo agent có dùng quota.
