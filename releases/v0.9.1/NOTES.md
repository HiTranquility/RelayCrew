# RelayCrew 0.9.1

## Markdown starter pack / Bộ mẫu Markdown

Generated preview images/HTML are removed from the current repository and README, and retained only as ignored local QA artifacts. Historical 0.9.0 and earlier release archives stay unchanged.

- Bundle five editable role guides: Developer, Auditor, Repair worker, Primary manager and Supporting coordinator.
- Bundle four plain Markdown workflow guides: feature delivery, bug fix, useful quota maintenance and supplied-context Local/Cloud review.
- Add task brief and Definition of Done examples, plus bilingual instructions explaining exactly where to import/paste each file.
- Add **Setup → Input and response templates → Markdown examples** and the Command Palette action to reveal the installed examples folder. Copy/edit files before importing them through the existing editors.
- Samples do not execute automatically, set account/model IDs, change manager authority or grant permissions. Existing task snapshots and all 0.9.0 release assets remain unchanged.
- Validate shipped workflow files with an arbitrary existing account and all five role files through the real template snapshot validator. CLI remains the editing path; HTTP review requires supplied material and read-only mode.

Xem [examples/README.md](https://github.com/HiTranquility/RelayCrew/blob/v0.9.1/examples/README.md). Sao chép mẫu vào project, sửa nội dung rồi đính kèm cho đúng vai trò hoặc nhập workflow. Với checklist nghiệm thu, chép các dòng checklist vào ô Definition of Done; chỉ đính kèm file không tự điền bảng nghiệm thu.
