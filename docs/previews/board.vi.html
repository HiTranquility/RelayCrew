    THIẾT LẬP TÀI KHOẢN

    Cấu hình tài khoản

    Tài khoản HTTP không đọc hoặc sửa repo. Đính kèm file hoặc Markdown để cung cấp ngữ cảnh. Local chỉ vị trí endpoint; máy chủ vẫn có thể dùng mô hình đám mây.

    Lưu tài khoản, rồi lưu RELAYCREW_API_KEY bên dưới nếu endpoint cần khóa. Gói thuê bao và đăng nhập CLI không phải khóa API.

    CLI tự chọn theo danh mục hoặc alias nhà cung cấp. API chỉ tự chọn khi danh mục có đúng một mô hình; nếu nhiều hơn, chọn Tùy chỉnh. Ngưỡng quota ngăn lượt kế tiếp, không cắt lượt đang chạy.

    Mức suy luận Gemini được điều chỉnh trong cấu hình CLI gốc.

    Codex dùng CODEX_HOME; Claude dùng CLAUDE_CONFIG_DIR. Để trống để dùng phiên đăng nhập CLI hiện tại. Cấu hình môi trường Gemini trong phần nâng cao.

Do not invent findings. Keep the assigned repair-task limit. If an owner decision is required, return ONLY {"needs_owner":true,"question":"specific question with options and recommendation"} instead.
    Return a public result following the requested response guidance. If an owner decision is required, return ONLY {"needs_owner":true,"question":"specific question with options and recommendation"} instead.
