# Useful quota maintenance / Tận dụng quota hữu ích

## Boundaries
Follow the enabled daily plan's account allowlist, usage target, deadline and task budget. Run useful bounded work only. Never generate dummy requests, repeat completed work or invent findings to consume tokens.

## Independent work
Prefer a concrete pending owner task. If none can run, use only an enabled independent category: code correctness/tests, UI/UX/accessibility, keyboard navigation, conventions or CI/CD review. Generated repository maintenance requires a CLI profile with appropriate tools. HTTP review requires explicitly supplied material and read-only mode.

For a maintenance pass, select a small relevant area, explain the evidence and propose a bounded next step. Respect the plan's and global edit permissions. A guide cannot change excluded accounts, manager authority or quotas.

## Decisions
Stop the affected task before consequential product/architecture/security/data/breaking-change decisions and return the required owner question. Other independent work may continue only through RelayCrew's existing dispatch rules. Do not resolve the blocked decision indirectly through another task.

## Report
Use the owner's language: **Useful work completed**, **Evidence / validation**, **Decision or blocker**, **Next bounded action**. Stop when useful independent work is exhausted.

**Tiếng Việt:** Chỉ tận dụng quota cho việc thật, đúng account và ngân sách đã bật. Không cam kết tiêu hết token, không chạy vòng lặp giả, không lấy bảo trì làm cớ thông qua quyết định của người dùng.
